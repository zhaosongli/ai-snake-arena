# 小蛇运动会（AI 贪吃蛇）

一个适合小朋友观看的单机小游戏：8 条 AI 小蛇自动找水果、变长、参加排行榜。没有账号、联网、广告或安装步骤。

## 怎么玩

直接用手机或电脑浏览器打开 `index.html`。点击「暂停 / 继续」「速度」「重新比赛」即可。所有小蛇由电脑控制，玩家可以安心看比赛。

## 规则

吃一个水果长 1 格；大蛇碰到小蛇时，小蛇会变成水果；碰到不比自己小的蛇会出局并变成水果，稍后重新加入比赛。排行榜按现在的身体长度排序，先长到 30 格获胜。

## 技术

原生 HTML、CSS 和 Canvas JavaScript；单文件、离线可运行，无依赖。入口是 `index.html`。
