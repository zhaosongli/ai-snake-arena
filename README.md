# 小蛇运动会（AI 贪吃蛇）

一个适合小朋友观看的单机小游戏：3 条 AI 小蛇自动找水果、变长、参加排行榜。没有账号、联网、广告或安装步骤。

## 怎么玩

直接点开在线游戏：<https://zhaosongli.github.io/ai-snake-arena/>。Telegram 里的 HTML 附件预览可能不会运行脚本；请点这个网页链接，不要点旧的 HTML 文件。

也可以用手机或电脑浏览器打开 `index.html` 离线玩。点击「暂停 / 继续」「速度」「重新比赛」即可。所有小蛇由电脑控制，玩家可以安心看比赛。

## 规则

吃自己颜色的水果长 2 格，吃其他颜色的水果长 1 格（空间暂时不够时，剩余的 1 格会在下一次安全移动时长出来）；大蛇碰到小蛇时，小蛇会变成自己颜色的水果；碰到不比自己小的蛇会出局并变成水果，稍后重新加入比赛。排行榜按现在的身体长度排序，先长到 30 格获胜。

## 技术

原生 HTML、CSS 和 Canvas JavaScript；单文件、离线可运行，无依赖。入口是 `index.html`。
