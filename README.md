# 小蛇运动会（AI 贪吃蛇）

一个适合小朋友观看的单机小游戏：3 条不同颜色的 AI 小蛇，每条只有一个蛇头，自动找水果，也会碰到自己的身体长大。没有账号、联网、广告或安装步骤。

## 怎么玩

直接点开在线游戏：<https://zhaosongli.github.io/ai-snake-arena/>。Telegram 里的 HTML 附件预览可能不会运行脚本；请点这个网页链接，不要点旧的 HTML 文件。

也可以用手机或电脑浏览器打开 `index.html` 离线玩。点击「暂停 / 继续」「速度」「重新比赛」即可。3 条小蛇由电脑控制，玩家可以安心看比赛。

## 规则

草莓红、蓝蓝、橘子三条小蛇各有一个蛇头，水果仍有红、蓝、橘三色。蛇头碰到自己的身体时原地咬一口、身体不断开，增长 2 格；吃自己颜色的水果长 2 格，吃其他颜色的水果长 1 格。尾巴暂时没有空间时，欠下的长度在下次安全移动时补上。大蛇碰到小蛇时，小蛇变成自己颜色的水果；碰到不比自己小的蛇会出局，稍后重新加入。先长到 30 格的获胜。

## 技术

原生 HTML、CSS 和 Canvas JavaScript；单文件、离线可运行，无依赖。入口是 `index.html`。
